  Source Line: Defaults env_keep += "LD_PRELOAD HTTP_PROXY"
  Location:    docs/examples/policy/sudoers:3
  Description: The policy explicitly preserves dangerous environment variables: LD_PRELOAD. This can allow local users to alter runtime linker behavior, interpreter module paths, or pager/editor execution in elevated processes.
  Remediation: Remove dynamic library path, interpreter path, and shell/editor environment variables from 'env_keep' and 'env_check', and keep them in 'env_delete' in sudoers Defaults.
  Example Fix:
