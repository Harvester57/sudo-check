# Example Reports

This directory contains deterministically generated example outputs for every report format supported by `sudo-check`, together with the exact input files used to produce them.

## Single-Policy Scan Reports

Generated from the multi-file sample policy in [policy/sudoers](./policy/sudoers) (which includes [policy/sudoers.d/10-deploy](./policy/sudoers.d/10-deploy) and [policy/sudoers.d/20-ops](./policy/sudoers.d/20-ops)):

| Format | File | Description |
| :--- | :--- | :--- |
| **HTML** | [report.html](./report.html) | Self-contained offline interactive report with verbatim source lines, alias resolution, inherited defaults, triage panels, reference frameworks, and hardened baseline template |
| **Text** | [report.txt](./report.txt) | Plain-text ANSI-free report with `Tags`, `Defaults`, `Source Line`, `Example Fix`, and `Reference` blocks |
| **JSON** | [report.json](./report.json) | Machine-readable structured `AuditResult` with `source_line`, `tags`, `inherited_defaults`, `remediation_code`, `exploit_poc`, and SHA-256 `fingerprint` |
| **SARIF** | [report.sarif](./report.sarif) | SARIF v2.1.0 report sorted deterministically for GitHub Code Scanning and CI security integrations |
| **PDF** | [report.pdf](./report.pdf) | Deterministic vector PDF report with severity summary, source line blocks, remediation code, and exploit references |

Regenerate all five single-policy formats:

```bash
sudo-check scan docs/examples/policy/sudoers -f text,json,sarif,html,pdf -o docs/examples
```

## Fleet Merge Reports

Generated by aggregating three host JSON reports from [fleet-inputs/prod-web-01.json](./fleet-inputs/prod-web-01.json), [fleet-inputs/prod-db-01.json](./fleet-inputs/prod-db-01.json), and [fleet-inputs/staging-app-01.json](./fleet-inputs/staging-app-01.json):

| Format | File | Description |
| :--- | :--- | :--- |
| **Fleet HTML** | [fleet-report.html](./fleet-report.html) | Consolidated fleet-wide host risk ranking and rule prevalence dashboard |
| **Fleet CSV** | [fleet-report.csv](./fleet-report.csv) | Tabular host risk breakdown for spreadsheets and BI pipelines |
| **Fleet JSON** | [fleet-report.json](./fleet-report.json) | Structured fleet aggregation summary for automation |

Regenerate all three fleet formats:

```bash
sudo-check merge docs/examples/fleet-inputs/prod-web-01.json docs/examples/fleet-inputs/prod-db-01.json docs/examples/fleet-inputs/staging-app-01.json -f html,csv,json -o docs/examples
```
